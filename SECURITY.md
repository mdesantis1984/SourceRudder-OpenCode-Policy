# Security Policy

## Reporting a vulnerability

Because this is a private repository, report potential vulnerabilities through
the existing private repository collaboration channel. Do not include exploit
details, credentials, tokens, or personal data in ordinary issue content.

If you do not have repository access, ask the repository owner through an
existing private collaboration channel for a secure reporting route. This
repository does not publish a separate security email address or public
disclosure channel.

## Report contents

Provide the affected version or commit, impact, reproduction steps, and any safe
mitigation you have identified. Keep sensitive proof of concept material private.

## Scope

This policy covers this companion plugin only. SourceRudder upstream reports must
follow the guidance in the [SourceRudder repository](https://github.com/mdesantis1984/SourceRudder).
