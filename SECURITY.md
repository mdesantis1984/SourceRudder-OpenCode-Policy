# Security Policy

[English](SECURITY.md) | [Español](SECURITY.es.md)

## Reporting a vulnerability

Use the repository's [private vulnerability reporting form](https://github.com/mdesantis1984/SourceRudder-OpenCode-Policy/security/advisories/new)
when it is available. Do not assume that the form is enabled until GitHub confirms
it after the publication gate.

If the form is unavailable, open a minimal public issue requesting a private
reporting channel. Do not include vulnerability details, exploit material,
credentials, tokens, or personal data in that issue. This repository does not
publish a security email address or another private contact.

## Report contents

After a private channel is confirmed, provide the affected version or commit,
impact, reproduction steps, and any safe mitigation you have identified. Keep
sensitive proof-of-concept material private.

## Scope

This policy covers this companion plugin only. SourceRudder upstream reports must
follow the guidance in the [SourceRudder repository](https://github.com/mdesantis1984/SourceRudder).
