# Política de seguridad

[English](SECURITY.md) | [Español](SECURITY.es.md)

## Notificación de una vulnerabilidad

Use el [formulario privado de notificación de vulnerabilidades](https://github.com/mdesantis1984/SourceRudder-OpenCode-Policy/security/advisories/new)
del repositorio cuando esté disponible. No asuma que el formulario está habilitado
hasta que GitHub lo confirme después de la puerta de publicación.

Si el formulario no está disponible, abra un issue público mínimo para solicitar
un canal privado de notificación. No incluya detalles de la vulnerabilidad,
material de explotación, credenciales, tokens ni datos personales en ese issue.
Este repositorio no publica una dirección de correo de seguridad ni otro contacto
privado.

## Contenido del informe

Después de que se confirme un canal privado, proporcione la versión o el commit
afectado, el impacto, los pasos de reproducción y cualquier mitigación segura que
haya identificado. Mantenga privado el material sensible de prueba de concepto.

## Alcance

Esta política cubre únicamente este complemento asociado. Los informes sobre
SourceRudder ascendente deben seguir la guía del [repositorio de SourceRudder](https://github.com/mdesantis1984/SourceRudder).
