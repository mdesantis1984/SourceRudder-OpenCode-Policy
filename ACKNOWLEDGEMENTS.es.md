# Reconocimientos

SourceRudder Policy reconoce los proyectos y comunidades de código abierto que
hacen posible este complemento:

- [SourceRudder](https://github.com/mdesantis1984/SourceRudder/tree/1a2741bfc9b4b9742f0683bd1b1e6738078df35e), cuyo perfil de repositorio fijado y contratos de herramientas de investigación sirvieron de referencia para este complemento.
- [OpenCode](https://opencode.ai/docs/plugins/) y su API de complementos.
- [Node.js](https://nodejs.org/), [TypeScript](https://www.typescriptlang.org/) y [esbuild](https://esbuild.github.io/) para la cadena local de compilación y verificación.
